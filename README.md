# 碳信用披露证据助手

## 项目目标

构建一个面向碳信用披露审核场景的 RAG 系统。

系统通过检索可追溯的登记记录、规则文件和披露样本，为用户问题提供带来源的证据回答，辅助人工审核人员理解碳信用声明与登记证据之间的关系。

## V1 功能范围

- 导入静态、可追溯的碳信用相关文档；
- 对用户问题进行语义检索和关键词检索；
- 返回基于证据的回答；
- 展示来源文件、Chunk 和后续可扩展的页码信息；
- 当资料不足时明确提示“证据不足，需要人工复核”。

## V1 不做什么

- 不实时抓取互联网或登记机构数据；
- 不直接认定任何企业存在绿洗行为；
- 不让大语言模型猜测缺失的项目状态或数量；
- 不在 V1 接入风险分类模型和 SHAP。

## 后续计划

1. 建立 Hybrid Search 基线；
2. 加入 Reranker；
3. 建立检索与回答评测集；
4. 接入结构化登记记录核对；
5. 接入 XGBoost 风险分流和 SHAP 解释；
6. 实现 Web Demo、API 和 Docker 部署。
