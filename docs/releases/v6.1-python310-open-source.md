# V6.1 — Python 3.10 与开源运行路径

V6.1整理本地安装、模型配置和公共文档，不改变 V6 的 Agent 图结构。

## 运行环境

- Windows Python 3.10.11；
- PyTorch 2.11.0+cu128；
- LangChain 1.3.18；
- LangGraph 1.2.11；
- langchain-deepseek 1.1.0；
- Streamlit 1.62.0。

项目仍声明 `requires-python = ">=3.10"`。Python 3.10 是本版本的本地验收环境，
不是对其他受支持版本的排除。

## DeepSeek

Custom Harness 和 LangGraph Runtime 的默认模型统一为 `deepseek-v4-flash`，Base URL
为 `https://api.deepseek.com`。工具循环默认设置 `DEEPSEEK_THINKING=disabled`，
避免默认思考模式耗尽较小的输出 token 配额。Runtime 创建时会加载项目根目录的 `.env`，因此
CLI、FastAPI 和 Streamlit 使用相同配置。

`.env` 不进入 Git。公开仓库只提供 `.env.example`，其中不包含真实密钥。

## 验收

发布前应完成：

```powershell
& .\.venv\Scripts\python.exe -m unittest discover -s tests -v
& .\.venv\Scripts\python.exe scripts\evaluate_agent_routes.py
& .\.venv\Scripts\python.exe scripts\evaluate_v5_harness.py
& .\.venv\Scripts\python.exe scripts\evaluate_v6_runtime_comparison.py
& .\.venv\Scripts\python.exe -m pip check
```

还需要启动 Streamlit，检查四个页面，并使用配置的 DeepSeek Key 完成一次最小 API
调用。API 调用验证连通性，不代表真实任务质量。
