# V6.1.1 — Streamlit 新请求状态修复

V6.1.1 修复 Streamlit 控制台在生成新 Request ID 时修改已实例化控件状态而触发的
`StreamlitAPIException`。

新请求按钮改为通过 `on_click` 回调在脚本重跑前更新幂等键，同时清除上一请求的
回答和事件面板。会话 Session ID 保持不变，因此新问题可以获得独立 Request ID，
多轮会话记忆仍然连续。

验证结果：

- Python 3.10 完整测试集 43 项通过；
- 浏览器点击后 Request ID 成功变化；
- 页面未出现 `StreamlitAPIException`；
- Streamlit 测试计数与公开文档同步为 43。
