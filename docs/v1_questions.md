# V1 可核验问题范围

## PDF 披露文件

1. 某企业在报告中提出了什么气候或减排目标？
2. 某企业披露了哪些碳排放、能源使用或碳信用相关信息？
3. 某项气候行动的进展、期限或适用范围是什么？
4. 某个结论在报告的哪一页、哪个章节有依据？

## 登记数据库

5. 指定碳信用项目编号对应的登记机构、项目状态是什么？
6. 指定项目已签发、已注销和剩余的碳信用数量分别是多少？
7. 当项目编号不存在，或资料不足以回答时，系统必须如何回复？
# 中文资料新增问题

8. 根据《温室气体自愿减排交易管理办法（试行）》，注册登记系统记录哪些信息？
9. 自愿减排项目申请登记时需要满足哪些核心条件？
10. 中国平安在 2024 年披露的建筑碳信用案例中，减排量和登记挂牌信息是什么？
11. 浙江双环传动如何描述高质量碳信用在减排目标中的作用？

## 回答边界

- 只根据检索到的原始资料回答；
- 回答必须能返回来源文件和页码；
- 找不到证据时，回答“证据不足，需要人工复核”；
- 不判断企业是否构成“绿洗”。
