# V3 风险审核辅助范围

## 目标

在已核对的本地登记记录与用户提供的碳信用声明字段基础上，输出风险审核辅助状态，不对企业是否绿洗、违法或合规作出自动结论。

## 模型性质

V3 使用 XGBoost 二分类模型输出高风险概率。`low_risk`、`high_risk` 和 `review_required` 是审核决策状态，不是模型原生的三分类标签。

## 输入字段

- 由本地登记记录提供：登记机构、项目类型、国家、登记状态、已签发数量、已注销数量；
- 由用户填写：声明数量、声明语境、声明语气；
- 由程序计算：声明数量与可核对登记数量之间的差异比例、登记状态风险标记。

## 决策边界

1. 项目 ID 未精确匹配、关键字段缺失或证据不足时，输出 `review_required`；
2. 仅在证据完整时，才依据模型高风险概率给出 `low_risk` 或 `high_risk` 辅助信号；
3. 所有结果均需展示登记记录来源，并建议人工复核。

## 论文模型复用限制

论文最终推荐模型使用结构化审核特征。其历史实验包含生成压力测试数据，严格真实验证样本量较小。因此，当前项目将复用其特征设计和训练方法，在当前环境重新训练并重新评估，而不直接部署旧 `.joblib` 模型。

## 当前基线与阈值限制

当前 Python 3.10 环境重新训练后，严格真实验证集的 ROC-AUC 为 1.000，但默认 0.50 分类阈值下 F1 为 0.000。这表明模型分数可区分正负样本排序，但默认概率阈值不适用于该小型外部验证集。

在该验证集上，0.35 阈值的诊断 F1 为 0.875；该数值仅用于解释概率分布，不可直接作为部署阈值，因为不能使用最终验证集标签调参。

后续阈值将仅使用从合成训练数据中独立划分出的校准集确定。留出集、生成压力测试集和严格真实验证集仅用于评估。

## 当前部署边界

在完成独立校准并获得更大规模真实验证数据前，系统将模型输出展示为“实验性高风险信号”。对于新输入、项目 ID 未精确核验、关键字段缺失或概率处于不确定区间的案例，系统默认输出 `review_required`。

## 独立校准结果与当前限制

使用 70% 合成训练集训练、10% 合成校准集选阈值、20% 合成留出集评估后，高风险阈值被选为 0.01，且未找到满足低风险可靠性目标的阈值。

该策略在合成留出集上的高风险 Precision 为 0.931，低于校准目标 0.950；严格真实验证集上的高风险 F1 为 1.000，但该集合仅有 16 条案例。

因此，当前版本不将校准后的概率阈值直接用于真实企业声明的自动 low_risk 或 high_risk 结论。模型分数仅作为实验性风险信号；面向实际输入的默认结果仍为 `review_required`，直到获得更大规模、独立标注的真实验证数据。

## 数量核对边界

V2 登记记录中的已签发、已注销和剩余数量属于项目聚合数据，不能自动视为某一企业声明对应的可核对数量。

当用户输入声明数量时，系统必须同时要求提供与该声明单位、Vintage、用途或注销记录相匹配的已核对数量及其证据来源。只有两者处于相同核对口径时，才允许计算数量差异比例。

若只有项目聚合数量，系统可以展示该数量作为背景信息，但必须输出 `review_required`，不得据此自动判定声明数量一致或不一致。
